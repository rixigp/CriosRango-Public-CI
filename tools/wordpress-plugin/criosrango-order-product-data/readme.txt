Enriches the existing authenticated /criosrango/v1/orders-detailed response with product_id and image_url when an order line can be matched uniquely and strictly to a WooCommerce line item.

This plugin does not register or replace any REST route and does not change authorization. Install and activate it in WordPress to enable enrichment.
